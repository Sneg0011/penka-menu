Проект — QR-меню кофейни «Пенка» (Next.js 16, статическая выгрузка `output: "export"`, React 19, three.js, свой WebGL-шейдер). Прочитай README.md и DESIGN.md, AGENTS.md (у Next 16 свои правила — сверяйся с node_modules/next/dist/docs). Сеть не нужна, новые зависимости не ставь. Не трогай print/, scripts/shots/, docs/plans/. Не коммить.

Задача: убрать лаги при прокрутке и привести вид в порядок. Заказчик смотрит с компьютера (телефон в рамке по центру) и с телефона 390 px.

## 1. Лаги (главное)
Замер (headless Chrome с видеокартой, телефон 390×844 @3x, процессор ×4 медленнее, 9 с плавной прокрутки на 55 % страницы):
- как есть: 21 кадр дольше 50 мс, 17 долгих задач (1,3 с), ScriptDuration 1,5 с;
- без чанка шейдера перелива (фон падает на CSS-градиенты): 4 кадра > 50 мс, 3 долгие задачи (0,2 с);
- «уменьшить движение» (без шейдера и без 3D): 0 и 0.
Значит, основная цена — шейдер перелива (`src/motion/pourShader.ts`, `PourBackground.tsx`, `pour.ts`, `useSectionProgress.ts`), остальное — 3D-стаканчик (`src/motion/Cup3D.tsx`, по README сборка карты окружения PMREM блокирует главный поток ~0,5 с даже на настольной видеокарте).

Сделай:
1.1. Шейдер перелива: холст рисовать в пониженном разрешении (фон мягкий и размытый — достаточно 0,5 от CSS-пикселей, без умножения на devicePixelRatio; растягивает CSS), упростить фрагментный шейдер (меньше октав шума/итераций), на кадр — минимум JS (без аллокаций, без чтения layout в цикле). Рисовать только когда на экране есть граница разделов (зона перелива) или идёт дрейф; когда граница ушла с экрана — цикл стоит, а фон раздела — тот же цвет, что даёт CSS (без скачка цвета). Поведение, ради которого он сделан (перелив «молоко в эспрессо» привязан к прокрутке, сторож кадров, `/?pour=slow`, запасной CSS-путь), сохранить.
1.2. 3D-стаканчик: убрать блокирующую сборку PMREM (освещение — обычными источниками света или маленькой заранее сгенерированной текстурой окружения без PMREM на главном потоке), ограничить pixelRatio холста до 1.5, рендерить только по изменению прокрутки и только пока стаканчик виден (IntersectionObserver), вне экрана — ноль кадров. Задержку старта 4 с оставить.
1.3. Посмотри, нет ли ещё работы на каждый кадр прокрутки в `SectionCarousel.tsx` и `useSectionProgress.ts` (setState на каждый scroll, чтение offsetTop в цикле и т. п.) — если есть, убери.

## 2. Вид
2.1. Строка позиции в меню (`ItemRow.tsx`, `TasteDots.tsx`, стили в `globals.css`) сейчас перегружена: строка значков (кубик, полукруг, снежинка) с точками вкуса — непонятный шифр, «примерно» стоит дважды (под ценой и курсивом в строке объёма), чипы аллергенов и «можно на растительном» на каждой позиции. Сделай спокойно и читаемо:
- название; под ним одна короткая человеческая характеристика вкуса, собранная из шкал (например «сладкий · мягкий», «с горчинкой · крепкий», «с кислинкой»), без значков; ниже «250 мл · ≈ 120 ккал»;
- цена справа: «≈ 270 ₽» и под ней мелко «примерно» — эту пометку у оценочных цен ОСТАВИТЬ (правило честности из README); курсивное «примерно» в строке объёма убрать (≈ у калорий его заменяет);
- чипы аллергенов из строки убрать (они есть в шторке позиции); «можно на растительном» оставить одной короткой меткой только там, где это правда (как сейчас по `plantMilk`);
- точки вкуса с подписями остаются в шторке позиции (`ItemSheet.tsx`) — там они понятны.
2.2. Липкая шапка (логотип, «концепт AVA», карусель разделов — `Header.tsx`, `SectionCarousel.tsx`): на светлых разделах сейчас под ней мутная тёмная полупрозрачная полоса. Фон шапки должен идти от цвета текущего раздела (светлый раздел — светлая шапка, тёмный — тёмная), без грязной полупрозрачной тьмы; текст — цветом `ink` раздела. Чип «концепт AVA» и логотип читаются на любом разделе.
2.3. Вид с компьютера (`PhoneFrame.tsx`, стили рамки): сейчас тёмный телефон на пустом бежевом поле, по краям мелкий текст — выглядит недоделанно. Сделай сцену: тёмный кофейный фон (цвета раздела «Кофе», можно мягкий радиальный свет за телефоном), слева крупно «Пенка» (тот же шрифт, что в герое) и 2–3 короткие строки, что это (QR-меню для гостей за столом: состав, вкус, цена, подбор по привычке), справа — QR-код текущего адреса страницы (`location.href`, рисовать на клиенте библиотекой `qrcode` — она уже в devDependencies; перенеси в dependencies, грузи лениво только на широком экране) с подписью «Наведите камеру — откроется на телефоне». Пометка «Концепт AVA AGENCY… Не официальный сайт» остаётся видимой. Без моно-шрифтов, без надписей прописными над заголовками, без градиентного текста.
2.4. Кнопки привычек на первом экране (`HabitPicker.tsx`) не трогай по смыслу; если правишь стиль, то только чтобы они выглядели тактильнее (не «серые плашки со стрелкой»), без потери контраста.

## Ограничения
- Честность: «≈» и «примерно» у оценочных цен, «пример» у отзывов и «берут вместе», футер-пометка — сохранить (README, раздел «Метки честности»).
- Ширина 360–430 px без горизонтальной прокрутки; цена видна целиком у самых длинных названий.
- Первая загрузка JS не должна вырасти больше чем на 5 КБ gzip (qrcode — только ленивым чанком на широком экране).
- Контраст текста ≥ 4,5 на всех фонах разделов.
